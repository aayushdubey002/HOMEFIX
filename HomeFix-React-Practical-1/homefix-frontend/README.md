# HomeFix React Frontend

This project follows the structure of the Full Stack Java Practical Experiment No. 03:
- React.js component-based UI
- Bootstrap and Bootstrap Icons
- Axios API service layer
- useState and useEffect
- Controlled forms
- Dynamic booking table
- API fallback sample data

## Run

```bash
npm install
npm run dev
```

Open the URL shown by Vite, normally:

http://localhost:5173/

## Backend endpoints expected

GET  /api/dashboard/stats
GET  /api/bookings/recent
POST /api/service-requests
POST /api/services

If the backend is not running, the frontend automatically shows local sample data so the UI can still be demonstrated.
